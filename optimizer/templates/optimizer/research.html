1. Prescriptive Optimization Problem Formulation

The prescriptive optimizer formulates nutrient supplementation as a non-linear constrained minimization problem solved via Sequential Least Squares Programming (SLSQP):

minimize: J(ΔN, ΔP, ΔK) = (c_N · ΔN) + (c_P · ΔP) + (c_K · ΔK) + λ(ΔN² + ΔP² + ΔK²)

subject to: ŷ(N + ΔN, P + ΔP, K + ΔK, pH, Rainfall, Crop) - Y_target ≥ 0

bounds: ΔN ∈ [0, 200], ΔP ∈ [0, 120], ΔK ∈ [0, 120] (kg/ha)

*Where c_N = $1.20, c_P = $1.50, c_K = $0.90 are input unit costs per kg, and λ = 10⁻⁴ provides Tikhonov regularization to maintain agronomic balance.
